# Security policy

## Reporting a vulnerability

Report vulnerabilities privately by email to <security@lotuswebagency.com>. Please do not open a public issue for a security problem. Include the package version, a description, and a sample document or steps that reproduce it. You will get an acknowledgement, and we will agree on a disclosure date with you once the fix is ready.

## Supported versions

Only the latest published release of `@lotuswebagency/sitemap-inspector-core` receives security fixes.
